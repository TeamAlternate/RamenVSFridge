遊び方

ラーメンと冷蔵庫の鬼ごっこバトルです。
制限時間は3分です。

ラーメンの攻撃：冷蔵庫に当たると、トッピングを一つドロップ
冷蔵庫の攻撃　：ラーメンに当たると、残り時間の減少を加速

-----------------------------------------------------------
ラーメンの勝利目標

制限時間内にラーメンのトッピングを集めて、
二郎系ラーメンを目指しましょう！

時間内にトッピングを20個集めることで勝利
ゲーム内の焚火に触れることで、制限時間が少しずつ長くなっていきます。

-----------------------------------------------------------
冷蔵庫の勝利目標

3分間ラーメンから逃げ切って、
ラーメンを冷やしましょう！

時間切れまでにラーメンがトッピングを20個集めることができなかったら勝利

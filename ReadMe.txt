===========================================================
遊び方

ラーメンと冷蔵庫の鬼ごっこバトルです。
ラーメンが冷えるまでの制限時間は3分です。

ラーメンの攻撃：冷蔵庫に当たると、トッピングを一つドロップ
冷蔵庫の攻撃　：ラーメンに当たると、ラーメンを冷やして残り時間の減少を加速

-----------------------------------------------------------
ラーメンの勝利目標

制限時間内にラーメンのトッピングを集めて、
二郎系ラーメンを目指しましょう！

ラーメンが冷え切る前にトッピングを20個集めることで勝利
ゲーム内の焚火に触れることで、温度(制限時間)が少しずつ上がって(延びて)いきます。

-----------------------------------------------------------
冷蔵庫の勝利目標

ラーメンが二郎系ラーメンになる前に、
ラーメンを冷やしきって残念なラーメンにしましょう！

ラーメンがトッピングを20個集める前にラーメンを冷やしきることで勝利

独自に実装したポイント・ＰＲポイント

・カメラの動き
　　カメラの移動・ズームを滑らかにして
　　画面酔いしにくくなるように工夫してます
　　実は内部はフレームレートに依存しない処理方法になってます
・シーン遷移
　　関数呼び出し一回でシーン遷移・アニメーション再生を一括で発動できるようにしてます
・インプットシステム
・ステージ

-- ブラッシュアップ --

・バランス調整
　　テストプレイを重ねて一方的にどちらかが強くならないように調整をしました。
　　これにより、何度もプレイを重ねることで高度な読みあいが発生すると思われます
・各種演出、及びＵＩ
　　ゲーム内の雰囲気と合うＵＩを設定するほか、
　　それぞれの演出、効果音にこだわりました。
